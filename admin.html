Add Work

Images and videos are now hosted for free with the site on GitHub, not Firebase Storage (which now requires a paid billing account). To add a piece:

  1. Put the file in E:\AI work\portfolio-media\inbox\ on your PC.
  2. Ask Claude to "add it to the portfolio" with the section, caption, and description, or run node tools/add-media.js from the portfolio folder.

It gets compressed, a thumbnail is made, and it shows up on the site within a couple of minutes. To remove or re-caption a piece, edit media/gallery.json.
